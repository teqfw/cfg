# Distribution

`@teqfw/cfg` distributes this consumer skill at `skills/teqfw-cfg/`.

Installed-package consumers start with `SKILL.md`; detailed, self-contained references are under `references/`. The skill must not depend on repository-only paths, `ctx/`, or a host project's source tree.

For repository work, the mounted cognitive context remains authoritative. The distributed skill only defines supported use of the installed package.
